# u14-results

Static page published with GitHub Pages at https://romshes.github.io/u14-results/ (served from `main`).

- `index.html` is generated. Don't edit it by hand: change `tools/template.html` or the data, then run
  `python3 tools/validate.py && python3 tools/build.py && python3 tools/check_page.py`.
- To refresh the results, follow `UPDATING.md` step by step.
- Keep the page design as it is unless the owner asks for changes.
